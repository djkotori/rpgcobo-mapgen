### 概要と目的

このドキュメントは **ワールドマップ画像生成仕様書** です。  


- 1ピクセルが、1ブロック（1キャラと同サイズ）に対応する、2D RPGのフィールドマップの画像を生成することを目的とします。
- 真上から見下ろしたトップビューのワールドマップ画像を生成します。
- レトロな2D RPGのように、1ブロックは、平原、森、川、砂浜などのバイオームで構成されます。
- バイオーム色は「単色」です。色とバイオームは1対1で対応します。
- この画像を更に加工して、最終的なゲームのハイトマップやテクスチャマップを生成することを想定しています。
- 出力は png 画像です。バイオームを色分けして表示します。

---

### データモデルとフォーマット

#### png 画像
- 256x256ピクセルが標準で、64x64～512x512までの範囲で生成可能です。
- 1ピクセルが、1ブロックに対応します。

#### バイオーム
```cpp
enum MapGenBiomeID
{
	PLAIN = 0,			//	標準的な陸地
	DESERT = 1,
	FOREST = 2,
	MOUNTAIN = 3,		//	通行不能
	EXMOUNTAIN = 4,		//	通行不能
	ROAD = 5,			//	1ブロック幅の道路
	BRIDGE = 6,
	RIVER = 7,			//	通行不能
	LAKE = 8,			//	通行不能
	SEA = 9,			//	通行不能
};
```
- **決定要素**：高さ・傾斜・湿度・水距離・ノイズなどをテーブル駆動で評価する。

### WorldMapImageGenerator 仕様

#### sample/worldmap 特徴分析（仕様化）
- 地形シルエットは「大陸1～2 + 小島群」または「外周が山壁で囲まれた内海型」の2系統が多い。
- 海は単なる外周ではなく、湾・海峡・内海・細い水路があり、陸を分断しつつ橋で再接続される。
- 河川は 1～3 本の主流があり、蛇行しながら海へ流入する。支流や湖を介するケースもある。
- 山地は「壁（境界）」「尾根（通行分断）」「塊（ランドマーク）」として配置される。森林は大中小の塊で分布し、通行の迷路性を作る。
- 砂漠は海岸沿いや盆地に 1 領域程度出現し、他バイオームとのコントラストを作る。
- 道路は 1 ブロック幅で、町・城・塔などの要所を結ぶネットワークになる。基本は直線・直角で、必要箇所のみ斜め接続。
- 橋は「道路が河川/海峡を横断する必須点」に限定され、地図上のゲートとして機能する。
- 全体として「通行不能（海/川/山/森）で区切る -> 道路と橋で再接続する」構造が強い。

#### 目標地形
- sample/worldmap 内の画像を参照。これらの画像のような、変化にとんだトップビューのワールドマップ画像を生成することを目標とする。
- 海又は山や谷に囲まれており、独立した地形が道や川や内海でつながっている。
- 道は、陸地の要所要所を繋げるようにネットワーク化して配置される。
- 道は、直角、直線で構成されるが、曲がり角などや一部の区間では斜めの線になる。
- ランダム性が高く、生成のたびに毎回違った意外性のある地形が生成される。

#### 生成アルゴリズム概要
- 下記の 10 ステップで生成し、最終的に `MapGenBiomeID` の 2D 配列へ確定する。

1) 生成モード決定（マクロ構図）
- seed から構図モードを抽選する。
	- `archipelago`: 外洋 + 複数島
	- `continent`: 大陸 + 周辺小島
	- `basin`: 外周山壁 + 内海
- モードごとに、陸率・水路本数・外周山率の初期レンジを変える。

2) 低周波ノイズで標高場を作成
- fBm(Perlin/Simplex) を使い `height(x,y)` を作る（低周波主体）。
- Worley 距離を混ぜて、入り江・半島のギザつきと大地の塊感を追加。
- `continent` モードでは、seed からランダムな中心・回転・離心率を持つ 1～3 個の楕円ローブ + ドメインワープで大陸シルエットを決定する（丸い単一大陸にならず、生成ごとに形が大きく変わる）。
- `archipelago` モードでは、主島 1～2 個 + 周辺にクラスタ配置された小島 3～6 個のローブで群島を構成する。島間には低強度の細い連結ローブを張り、地峡や小島チェーンとして到達性を保つ（ノイズで一部は水没し海峡になる）。
- `basin` モードの内部は中央ピークを持たないノイズ主体の起伏とし、seed ごとにランダムな中間半径の環状帯をわずかに持ち上げて「内海を囲む連続した陸のリング」を誘導する。
- `height` をヒストグラム正規化して sea level が狙いの陸率になるよう調整する。全モードで分位点により海面を再アンカーし、シルエット形状によらず陸率を安定させる。

3) 海・陸の一次分割
- `height < seaLevel` を `SEA` 候補とする。
- 連結成分を取り、外周と接続する水域を外洋、それ以外を内海/湖候補として保持する。

4) 地形骨格（山・外周壁・峠）の生成
- `height` と ridge noise から山稜候補を抽出し、尾根の細線化で主稜線を得る。
- 全モードで、標高しきい値ではなく「ランダム方位の帯状リッジノイズ + 標高 + Worley 尾根」のスコア上位セルを山に割り当てる（分位点選択で被覆率を保証）。山脈の位置・走向が seed ごとに変わり、中央集中や山の氾濫を避ける。
- `basin` モードでは外周に `MOUNTAIN/EXMOUNTAIN` のリングを優先生成する（リングは山被覆率の分位点選択から除外）。
- 山で完全閉塞しすぎないよう、峠セル（後で ROAD 通過可）を一定間隔で開ける。孤立した陸領域には 0-1 BFS で最小限の山を削って峠を通し、到達性を保証する。

5) 河川と湖の生成
- 山地/高標高点から 1～3 本の主流を選び、勾配降下 + ノイズで蛇行させて流路追跡。
- 下流で合流させ、外洋または内海まで到達させる。
- 低勾配盆地や閉塞地点は `LAKE` 化し、しきい値超過で溢流して再接続。
- 流路幅は原則 1 ブロック、下流/河口付近は 2 ブロックまで許容。

6) バイオーム割当（PLAIN / FOREST / DESERT）
- `moisture`（水距離 + 湿度ノイズ）と `height` でテーブル判定。
- 基本方針:
	- 海岸近傍低地: `PLAIN`
	- 水から遠く中標高: `FOREST`
	- 乾燥度が高い領域: `DESERT`
- `FOREST` は連結塊になるようモルフォロジー（膨張/収縮）で調整する。

7) POI 候補点と道路ネットワーク
- 可通行セル（主に `PLAIN`/`DESERT`）から、海岸・盆地・山麓・半島先端などに POI 候補を抽出。
- 候補点間で Delaunay 近傍または k-NN グラフを作成し、最小全域木 + 追加辺で道路骨格化。
- A*（移動コスト: 平地低、森中、山/水は不可）で 1 ブロック道路を敷設。
- 長距離の一直線を避けるため、一定間隔で折れ点（直角優先、低確率で斜め）を入れる。

8) 橋配置
- 道路経路が `RIVER/LAKE` を横断する最短点のみ `BRIDGE` を許可。
- 1 本の河川に対して橋が密集しないよう最小間隔を設ける。

9) 接続性修正と品質ゲート
- 可通行領域グラフで「主要 POI 同士が到達可能」か判定。不達なら道路再探索または峠追加。
- 海岸線のノイズが過剰な場合は平滑化、単調すぎる場合は湾/岬ノイズを再注入。
- 山・森・砂漠の面積率が範囲外なら閾値を再調整して再割当する。

10) 最終量子化と出力
- 優先順位で確定: `BRIDGE > ROAD > RIVER > LAKE > SEA > EXMOUNTAIN > MOUNTAIN > FOREST > DESERT > PLAIN`
- バイオームID配列を確定後、色テーブルで PNG 出力する。

#### 推奨パラメータ（初期値）
- `seaLevel`: 0.48（陸率目安 40～60%）
- `macroModeWeights`: `archipelago=0.35, continent=0.40, basin=0.25`
- `ridgeStrength`: 0.55
- `continentLandRatio`: 0.45..0.60（乱択。continent の陸率ターゲット。分位点で海面を再アンカー）
- `continentWarpAmp`: 0.07..0.16（乱択。大陸シルエットのドメインワープ量）
- `continentMountainCoverage`: 0.09..0.16（乱択。continent の山被覆率ターゲット）
- `archipelagoLandRatio`: 0.44..0.54（乱択。archipelago の陸率ターゲット）
- `archipelagoWarpAmp`: 0.05..0.12（乱択。群島シルエットのドメインワープ量）
- `archipelagoMountainCoverage`: 0.06..0.12（乱択。archipelago の山被覆率ターゲット）
- `basinLandRatio`: 0.36..0.44（乱択。basin の外周隆起前の陸率ターゲット。最終陸率はこれより高くなる）
- `basinMountainCoverage`: 0.08..0.13（乱択。basin 内部の山被覆率ターゲット。外周壁は含まない）
- `riverDensity`: 1.0（河川密度スカラー。主流・支流・湖の生成量に乗算）
- `mountainChainAttempts`: 10（近距離の山塊同士を山脈状に接続する試行回数）
- `mountainChainConnectDist`: 18（接続対象とする山塊間距離の上限セル）
- `mountainRidgeGapFillPasses`: 2（近傍の山点ギャップを埋めるパス回数）
- `riverCountMinMax`: 1..3
- `forestCoverage`: 0.18..0.35
- `desertCoverage`: 0.05..0.18
- `roadDensity`: 1.0（道路密度スカラー。POI数・分岐本数・最低道路被覆率に乗算）
- `roadExtraEdgeRate`: 0.15（MST に対する追加辺率）
- `bridgeMinInterval`: 18（セル）

#### 品質チェック指標（自動テスト用）
- 陸率: 0.35～0.70
- 可通行領域の最大連結成分率: 0.65 以上
- 河川総延長: `min(w,d) * 0.8` 以上
- 橋本数: 1～12
- 道路で接続された POI 率: 0.90 以上
- 同一バイオーム最大塊率（平原除く）: 0.45 未満

### パラメータ例とテスト出力

#### デフォルトパラメータ例
- **w**: 256  
- **d**: 256
- **seed**: 任意 uint32  
- **scale**: 1.0 地形の細かさを表すスケールパラメータ。1.0で標準。
- **riverDensity**: 1.0 川・支流・湖の密度係数（例: 0.7で疎、1.4で密）。
- **roadDensity**: 1.0 道路ネットワーク密度係数（例: 0.7で疎、1.4で密）。
- **mountainChainAttempts**: 10 山塊連結の試行回数。増やすと山脈化が進む。
- **mountainChainConnectDist**: 18 接続対象の最大距離。増やすと離れた山塊も連結される。
- **mountainRidgeGapFillPasses**: 2 山の細かい隙間を埋める回数。
- 他要検討

### ファイル構成とコードテンプレート

#### ファイル構成
- `doc/mapgen_world.md`（本仕様）
- `src/MapImageGenerator.h`（基底クラス。必要に応じて関数を追加）  
- `src/WorldMapImageGenerator.(h|cpp)`（基底クラス。必要に応じて関数を追加可）  
- `src/utils.(h|cpp)`（Worley/Perlin/quantizeの実装。必要な機能を要生成）
- `src/main.cpp`（exeのエントリーポイント。入力からパラメータを取ったり、出力をしたり、png画像を生成する。必要な機能を要生成）
- `src/CMakeLists.txt`（CMakeビルド設定。必要に応じて生成）
- `src/build.bat`（ビルド用バッチファイル）
- `src/build/mapimggen.exe`（ビルドで生成される実行ファイル）
- `src/include/*`（ライブラリヘッダー。zlib,lpng等）
- `src/lib/*`（スタティックライブラリ）
- `bat/*`（ビルド、テスト用バッチファイル。必要に応じて生成）
- `/mapimggen.exe`（ビルドで生成される実行ファイル。bat/build.batによって生成）

#### MapImageGeneratorクラス
- MapImageGeneratorクラスは、マップ画像生成の基底クラスです。
- WorldMapImageGeneratorクラスは、MapImageGeneratorクラスを継承して、ワールドマップ画像生成の具体的な実装を行います。
- main.cpp では、コマンドライン引数を解析して、WorldMapImageGeneratorクラスのインスタンスを生成し、マップ画像を生成し、ファイル出力します。

#### テスト出力ディレクトリ
- `out/$session/$index_*.*`（自動テストとサンプル出力。1セッションで複数の出力）

#### mapimggen.exe のコマンドライン仕様

```
mapimggen.exe -type world -w 256 -d 256 -seed 12345 [extra options] -dir tmp/mapgen/ -out filename [--data --png --report]
```

- `-type` : マップ生成器の種類。今回は `world`で、`dungeon`, `cave` なども追加されていく。
- `-w` : マップの幅（ブロック単位）
- `-d` : マップの奥行き（ブロック単位）
- `-seed` : 乱数シード。未指定の場合はランダム値を使用する。
- `[extra options]` : 追加パラメータ。`-p paramName=value` の形式で任意のパラメータを指定できる。
- `-dir` : 出力ディレクトリ。未指定の場合はカレントディレクトリに出力される。
- `-out` : 出力ファイル名。未指定の場合は `out` が使用される。
